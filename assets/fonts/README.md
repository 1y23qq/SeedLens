# Noto Sans JP

Noto Sans JP is embedded for both Japanese and Latin text. The regular face contains the interface glyphs, kana, Latin text, punctuation and JIS first-level kanji. The semibold face contains the interface glyphs. Windows Japanese fonts supply fallback glyphs for other user-entered text.

Source: [google/fonts, ofl/notosansjp](https://github.com/google/fonts/tree/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl/notosansjp).

The static 400 / 600 subsets are generated by scripts/prepare_fonts.py from NotoSansJP[wght].ttf and retain the font's SIL Open Font License. The full license is in OFL.txt and is embedded with the application notices.

The embedded .bin files use Dear ImGui's built-in stb font compression. scripts/font_pack.cpp and the vendored ImGui helper generate them from the checked-in static TTF subsets. Normal app builds use the prebuilt files.

The GUI subsets use the font's typographic ascender/descender for line metrics so that a 15-pixel GUI size renders at the intended em size. Glyph outlines are retained.
